API inspector

Every action in the app is a REST-style request. Open any call to see the request and response, just like browser dev tools.

Endpoints

MethodPathWhat it does
GET/menuList menu items and delivery fee
GET/orders?status=List orders, newest first (optional filter)
POST/ordersCreate an order (validated)
GET/orders/:idFetch one order
PATCH/orders/:id/statusMove to the next lifecycle status
POST/orders/:id/cancelCancel (only before it is out for delivery)
DELETE/ordersClear all demo data
